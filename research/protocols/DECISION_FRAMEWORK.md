# 决策、卖出、等待与风险框架

2026-10-08 UTC；状态 `UNTESTED_RESEARCH_FRAMEWORK`。这是每个真实 replay 需要填写的决策结构，尚无概率、交易、净收益或校准证据。

## 从事实到当前价格

1. **证据**：事实、发布时间、版本与来源；判断、传闻和不可用字段另列。只用 `available_at <= T` 的信息。
2. **经济路径**：需求 → 供给/资本开支 → 竞争/定价 → 企业利润 → 现金/资产负债表 → 股东每股现金。写主要时滞和可观测中介，不把产业方向直接变成股票方向。
3. **市场已知什么**：当时估值、同业相对值、历史分位（仅T前）、可得分析师预期、盈利修正、拥挤/仓位、期权（若有）与公告反应。缺共识或期权就标缺失，不从后续价格猜当时预期。
4. **Price-in**：用简单逆向估值写价格要求的增长、利润率、资本投入、回报与现金期限；不是精准目标价。区分好公司、好产业和当前价格下有利赔率。
5. **路径与不确定性**：基准/改善/恶化情景，范围而非伪精确点值；每个情景有哪些已知条件、未知变量和否证数据。模型记忆或时间戳不确定须降低研究可识别性，不能只调低概率蒙混过关。
6. **动作**：研究性分类 `BUY / HOLD / REDUCE / SELL / NO-TRADE / WAIT`；需要真实数据才可填资产、方向、概率区间与模拟执行。当前没有任何建议或模拟持仓。

## 反应不足与过度反应

`Underreaction` 候选机制：盈利上修持续、政策逐步落地、资本调整缓慢、机构重配与技术扩散有时滞。要问首次公告后是否仍有新信息、市场是否已计入、后续超额回报是否扣成本稳定。价格继续涨不足以证明反应不足。

`Overreaction` 候选机制：流动性冲击、被动赎回、短暂战争/商品/监管冲击。要区分暂时错杀与永久盈利/融资损伤；事先写资产负债表生存、现金流和事件持续条件。之后反弹不足以证明原冲击非基本面。

这些分类目前均是待测假说；没有独立对照/机制证据不能称因果。

## 概率、赔率与执行

预测必须定义事件，例如“预登记 horizon 的净超额回报超过预登记阈值”，再写宽概率范围；不把模糊“看好”纳入校准。预期回报和情景上/下行需要真实来源与假设，缺资料则 `null`。简化期望值 `P(success) × upside − P(failure) × downside` 只是二状态近似；多情景、尾部损失、相关性、流动性、成本与机会成本另列。

首次模拟执行在截止之后且信息公开后的下一可交易时点；不得用截止收盘偷取成交。计划重评/调仓至少每周一次间隔，明示下一决策日、交易日历与停牌/涨跌停规则。前向价格与标签只由锁定后的评估器读取。跨市场 FX、基金申赎、债券报价、退市/关闭与公司行动按数据契约处理。

## 卖出框架

| 类别 | 当时可识别的触发问题 | 不可混淆之处 |
|---|---|---|
| `PRICE_BASED` | 价格达到预登记的研究阈值了吗？ | 单纯涨幅不能证明逻辑失效；不能事后设置漂亮止盈点 |
| `THESIS_BASED` | 盈利修正、竞争优势、合同落实、信用或供需机制被什么证据否证？ | 用基本面证据，不因未来跌幅重写原论点 |
| `VALUATION_BASED` | 逆向估值需要的未来增长/资本回报是否超出已登记可支持范围？ | 趋势方向可对，价格仍可能透支 |
| `RISK_BASED` | 集中、杠杆、相关性、流动性、尾部亏损或资本约束是否越过风险预算？ | 风险减仓独立于证券基本面观点 |
| `OPPORTUNITY_COST` | 出现预登记可比较的更优替代了吗？ | 替代资产必须同币种/期限/成本可执行，不能用事后赢家 |

每个触发记录观测指标、来源、阈值、首次可得时间与下次周度可执行决策日。意外停牌/违约/清算是强制约束，原计划保留；不得事后把实际不可执行的风险阈值当已成交止损。用户后续真实风险约束优先。

## NO-TRADE / WAIT

等待可能因价格已透支、证据不可靠、催化不清、赔率一般、流动性弱或系统风险暴露而产生。填写：等待的具体原因、能解除等待的公开证据、下一周重评时点、现金/短债代理及其成本/收益口径、错过上涨与避免亏损的对照。等待是可评估决策，不能因后来上涨就自动判错，也不能因后来下跌就自动判对；按事前风险与期望值标准复盘。

## 仓位只研究原则

先检验生存、最大可承受损失、流动性与相关性，再讨论风险预算和分散。fractional Kelly 仅作理论上限敏感性，不用不精确概率计算“最优”仓位。本轮没有真实账户信息，所有仓位保持空值；不推导个人仓位建议。

## 复盘输出

锁定判断与结果分离。分类“对且理由对”“对但理由错”“错但过程合理”“错且可识别错误”“随机/无法归因”，并记录经济机制是否兑现、price-in 判断是否准确、成本/执行与数据局限。没数据时记录阻塞；不能以模板文本替代事前判断或声称获得经验。
