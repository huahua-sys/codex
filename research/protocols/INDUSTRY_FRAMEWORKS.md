# 行业差异与跨资产研究框架

2026-10-08 UTC；状态 `UNTESTED_RESEARCH_FRAMEWORK`。下列字段是寻找问题和经济机制的导航，不是已验证因子、权重或投资原则。现有资料没有任何行业实证支持。

## 共同的十一步检验

每个产业叙事依次追问：需求是否真实增长、可持续多久、供给多久扩张、资本是否涌入、是否价格战、什么资源稀缺、谁有议价权、谁得到利润、竞争是否侵蚀利润、现金如何归属股东、当前价格已经计入多少。缺一环就保留不确定，不以“好产业”推断“当前价格值得买”。

## 独立行业问题

| 行业 | 当时可见的关键量 | 机制与股东回报桥梁 | 反例、失效与 price-in 检查 |
|---|---|---|---|
| 软件 / AI | 渗透率、续费/留存、付费使用、切换成本、网络效应、经常性收入、毛利、compute 单位成本、CapEx与股权激励 | 使用/留存 → 定价与收入 → 计算/销售成本 → FCF → 稀释后的每股现金；检查算力拥有者与应用商谁获利 | 需求免费化、推理成本高、竞争压价、客户集中、赢家通吃假说未兑现；收入增长可能被CapEx/稀释吃掉；逆向估值要求多大增长 |
| 半导体 | 库存、订单取消、产能/利用率、设备交期、制程迁移、良率、ASP、CapEx、客户库存 | 需求与去库存 → 利用率/定价 → 毛利 → 资本开支后的现金；设计/代工/设备/存储分别分析 | 库存反弹不是终端需求；重复订单；产能随后过剩；节点投产延误；峰值盈利的低PE陷阱 |
| 资源 / 能源 | 库存、成本曲线、供给弹性、储量寿命、品位、新产能交期、地缘集中、许可、对冲 | 瓶颈与边际成本 → 商品价格 → 实现价格/成本 → 维护CapEx/税费 → 分红与净债务 | 高价诱发供给/替代；需求回落；税收与资本开支吞噬利润；商品方向正确但企业高成本/高负债；估值应看周期正常化现金 |
| 银行 | 信贷增量与结构、NIM、存款成本、资产质量、逾期/迁徙、拨备、资本率、负债稳定性 | 利差与手续费 → 信用损失 → 有形资本回报 → 可分配资本；以资本/资产质量而非工业企业FCF解释 | 低估值可能反映未计提损失；增长可能消耗资本；期限错配/存款外流；应比较正常化ROE与资本成本、而非只看PB |
| 医药 / 生物科技 | 管线阶段、预登记临床终点、公开试验设计、专利期限、批准、支付/报销、定价、竞争、现金 runway | 公开证据 → 条件化临床/监管情景 → 可销售量价 → 研发/商业化/融资 → 股东现金 | 临床与商业成功分开；不可按已知试验结果补事前概率；专利悬崖、报销限制、融资稀释；阶段成功率需要独立历史资料 |
| 公用事业 / 电力 | 负荷增长、rate base、允许回报、资本开支、融资成本、长期合同、燃料/现货暴露、监管时滞 | 负荷/投资 → 可获准资产基数/合同现金 → 资本回报与融资缺口 → 股东可分配现金 | 需求增长不保证获准ROE；资本开支需融资；固定合同与现货风险不同；利率变化影响贴现与借款成本 |
| 工业 / 资本品 | 订单、积压、交期、取消率、客户CapEx、维护需求、售后占比、营运资本 | 真实订单 → 执行收入/毛利 → 应收与库存回收 → 现金 | 订单口径变化、延迟/取消、客户融资困难、工程亏损；繁荣时扩产与估值同到顶 |
| 消费 / 零售 | 同店量价、渠道库存、促销、份额、留存、租金、劳动力、现金转化 | 真实销量/定价 → 单店经济 → 扩店资本效率 → 分红/回购 | 提价掩盖销量下滑、压货、低质扩店、周期刺激；品牌与回报需估值条件 |
| 房地产 / 建材 | 销售现金、去化、土地/供给、租赁率、到期债务、融资、资产重估口径 | 可回收现金与债权顺序 → 净资产/持续经营 → 股东剩余价值 | 账面资产非可实现价值；预售义务/担保、流动性断裂、稀释；地产开发与REITs分开 |
| 保险 | 承保纪律、赔付/准备金、保费增量、负债久期、投资资产、偿付能力 | 承保利润/浮存金成本 → 投资收益与资本需求 → 股东现金 | 隐藏准备金亏损、追逐保费牺牲质量、资产负债期限/币种不匹配；不能按银行NIM模板解释 |
| 通信 / 网络基础设施 | 连接/用户量、ARPU、流失、频谱、覆盖、CapEx、折旧与网络共享 | 稳定需求与竞争 → 现金毛利 → 维护/升级CapEx → 债务与分配 | 价格战、监管、技术更新、资本回报弱；新增流量未必提高每股FCF |

行业边界依据当时业务构成定义，跨业务公司拆分盈利/资本投入，而不是把今日“AI”等分类倒灌历史。行业术语与指标口径须由来源证实，未知数据留空。

## Capital Cycle、估值与类比

每个行业分别写需求、供给、资本进入、产能释放、竞争、价格和资本退出的时滞；记录周期错位与“需求上升但每股现金下降”反例。估值选择随经济结构变化：银行看可持续资本回报与资产质量，资源看正常化现金与成本曲线，软件看增长/成本/稀释路径，公用事业看获准回报与融资。所有估值都需要把当前价格反推到未来条件，不默认某倍数便宜。

历史类比同时列相似与差异：利率、通胀、信用、估值、产业阶段、竞争、政策、供应链、集中度、拥挤、技术、资产负债表与融资。分别判断哪些为核心因果条件、哪些只是表面叙事；未验证时只能称机制假说。

## Regime 与新闻

Regime 按 T 时可公开数据识别：通胀/利率/增长/信用/市场趋势/估值/流动性，阈值与数据 vintage 先登记。不能以未来是否衰退给 T 贴“衰退”标签参与特征。样本少时不增加复杂交互。

新闻分为政策宣布、政策实施、公司行动、盈利、行业数据、资本配置、内幕人、地缘、分析师观点与传闻。用户提出的“实际行动 > 有成本承诺 > 一手数据 > 政策执行 > 正式政策 > 管理层表态 > 分析师观点 > 媒体叙事 > 传闻”仅作为待检验的研究先验，不能未经案例检验设固定权重。

## 跨资产表达

同一变化比较可投资的股票/指数/ETF、主动基金（若有）、黄金工具、国债/债券基金、利率资产、现金/货币基金。先解释风险暴露，再比较同一币种、同一持有期、成本后的回报分布、回撤、流动性和机会成本。指数点位、商品现货、国债收益率并非自动可执行投资回报。

通胀、利率、信用或流动性冲击在不同资产中的表达只是研究问题，不提前规定最佳资产。证券和基金都可成为案例；资料可靠、可得时间可还原、真实可交易的样本优先，低流动性/覆盖不足的结论单列。没有数据时不选仓位或产品。
