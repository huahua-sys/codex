# 历史遮蔽复盘与前瞻验证协议

版本 1.0；2026-10-08 UTC。当前执行轮次 `ROUND_001`：`BLOCKED_DATA_REQUIRED`。尚未锁定任何真实资产判断，也未揭晓任何标签。

## 何谓盲性

LLM 可能从训练数据知道历史结果；隐去未来文件、改资产代号或规定“活在 T”不能抹除这种记忆。因此此协议的历史运行称 `MASKED_HISTORICAL_REPLAY`，是信息过滤和过程审计实验。它不能证明真实事前预测能力。若认识事件、价格走势或结局，记录 `MODEL_MEMORY_CONTAMINATION`，保留原记录，从主要验证集合隔离。

用于强验证的 `PROSPECTIVE_PREREGISTERED` 样本必须在预测锁定后才产生可评分结果；来源、时间戳和独立评估器应可核验。独立历史 holdout 能限制研究者读取与反复调参，但仍不能保证模型训练未见过它。匿名化只降低识别风险，不能消除该限制。

## 角色、目录与锁定

研究者只读预登记和 `ex_ante/`；数据管理员按契约制作输入；评估者在锁定后读取 `labels/`。单人或同一模型兼任时如实标记 `SEPARATION_LOGICAL_ONLY`，不能声称权限隔离。当前本地可写目录并非不可篡改系统。

每轮以后按下列结构保存；本轮尚无数据，不创建伪 ex-ante/标签记录：

```text
research/replays/<round_id>/
  preregistration.v001.md
  manifest.ex_ante.v001.json
  ex_ante/<episode_id>.v001.md
  locks/<episode_id>.v001.lock.json
  labels/<episode_id>.v001.json
  review/<episode_id>.v001.md
  access_log.jsonl
  amendments.jsonl
```

输入 manifest 包含各文件 SHA-256、来源、T、`available_at`、版本与过滤结果。锁定清单包含判断文件哈希、输入 manifest 哈希、预登记哈希、时间、操作者与污染申明。揭晓清单包含标签文件哈希、锁文件哈希、评估器版本和揭晓时间。未来改动只追加 `.v002` 和 amendment，引用原哈希、原因、影响；旧文件不覆盖。哈希只证明版本内容一致，不证明时间先后或未访问标签；强验证应使用独立见证或可信时间戳归档。

## 运行顺序与状态机

| 阶段 | 条件与动作 | 状态 |
|---|---|---|
| 0. 可执行性审计 | 审核历史 universe、源时间、版本、价格/行动、日历、基准与成本；缺失时保存阻塞 | `BLOCKED_DATA_REQUIRED` / `ELIGIBLE` |
| 1. 预登记 | 确认抽样框、信号/事件、horizon、主要检验、执行规则、对照、排除/停止条件及检验预算 | `PREREGISTERED` |
| 2. 冻结输入 | 过滤 `available_at <= T`，隔离未来与不确定时间；封存未来标签 | `INPUT_FROZEN` |
| 3. 判断 | 写当时环境、产业、估值、盈利、政策、新闻、资金、趋势、预期、合理路径；每点引用来源；缺失不补 | `EX_ANTE_DRAFTED` |
| 4. 锁定 | 写概率事件及区间、决策、执行/卖出/等待条件、失败机制；登记所有哈希与污染声明 | `EX_ANTE_LOCKED` |
| 5. 标签评估 | 独立计算各期总回报、成本、基准、FX、尾部风险、类别与成熟度 | `REVEALED` / `PENDING_HORIZON` / `UNRESOLVED_DATA` |
| 6. 复盘 | 对照原理由与后续机制，不修改原判断；归因与局限分别记录 | `REVIEWED` |

禁止 `BLOCKED_DATA_REQUIRED → REVEALED` 或先看到标签再补原概率。任何训练/读文件污染、规则修改或标签提前访问写入审计；污染样本可作为探索案例保留，但不能贡献独立确认结论。

## 先抽样，再分类

确认集合从历史可交易 universe × 预先排定的周截止点抽取；固定市场、时间跨度、最低流动性规则、缺失处理与随机 seed。不得用后续上涨、著名事件、未来“启动前”或未来危机定位 T。探索者可以事后选案例学习机制，但必须标 `EXPLORATORY / OUTCOME_SELECTED`。

以 T 时可见的候选信号分层抽样：信号出现与未出现的普通样本均纳入，并保存抽样概率。可按当时已知的行业、规模、估值、流动性和 regime 匹配；不能匹配未来信息。结果类别仅在锁定后由评估者根据预登记阈值生成：

| 类别 | 信号与事后标签关系 |
|---|---|
| `Positive Case` | 信号出现且达到预登记目标事件或决策效用标准；买入可以是上涨，SELL/WAIT 可以是避免损失或相对继续持有改善净结果 |
| `Negative Control` | 信号出现但未达到该假设目标标准；对照不自动等于因果反事实 |
| `False Negative / Missed Winner / Missed Risk` | 买入信号未出现但达到上涨目标，为漏掉赢家；SELL/WAIT 风险信号未出现但损失事件发生，为遗漏风险；两者按假设分别定义 |
| `Opposite Case` | 同类环境或信号出现，结果达到预登记反向标准 |
| `No-result / Ordinary Case` | 结果在预登记中性带或缺少具有经济意义的超额回报 |
| `UNRESOLVED_DATA` | 无法评价，不是无结果、亏损或零收益 |

类别允许交叉，例如反向案例也属于未成功的信号案例；统计必须定义互斥主标签与多标签附加字段，防止重复计数。标签中的“正向 / 反向”指预登记假设方向或决策效用，不能统一等同于股价上涨 / 下跌。无信号上涨、下跌和中性普通样本均保留。首轮不能保证上述结果类别各有固定数量；若缺类别，报告缺口，下一轮按新日历/行业扩展，不能回头搜索已知赢家填配额。专门事后补出的反例列为探索，不并入原确认样本。

## 交易与前向标签

截止 T 必须有时区及市场交易日历。首次模拟成交为 T 之后信息确已公开的下一可交易时点，预登记开盘、VWAP 等执行基准且数据须支持；不能按 T 的收盘价成交。计划再决策间隔至少一周。1 周定义为入场后五个完整交易时段或日历周后下一交易时点，二选一在看标签前锁定；1/3/6/12/24 个月采用同一预登记对齐规则。五年以上结构研究另立 horizon。

停牌、涨跌停、基金申赎截止、节假日、退出困难按实际约束顺延或记录不可成交，不能填虚拟价格。最低成本模型含佣金、税费、价差、滑点、持有/基金费用与跨币种换汇；不重复扣已含于净值的费用。报告本币和统一报告币种总回报，包含股息再投资、公司行动、清算/退市终值与可实现退出。基准、现金/短债代理使用相同起止和币种。缺行情或未知退市终值保持空值并报告覆盖。

`NO-TRADE / WAIT` 记录其现金/短债代理、解除等待条件与下一周复核时间；只评分等待所造成的机会成本和风险，并保留该判断对证券方向的独立预测，不能把未交易等同于预测错误。

## 简单统计、校准与归因

首轮优先报告样本数、覆盖率、总/净超额收益分布、中位数、分位数、命中率、胜负幅度和期望值。阈值、主要 horizon、主要指标和最低经济意义先登记；其余 horizon 为次要描述，防止从六个结果中择优。

匹配比较和简易 event study 控制当时行业/规模/估值/regime；仅在可识别条件下讨论因果。多个同周/同行业事件及重叠 horizon 不独立，采用日期/资产簇的简单 block bootstrap 或非重叠样本；报告有效独立样本和区间。参数只检验少量事先有理由的邻近稳定区间；保存所有测试，禁止寻找最佳点。walk-forward 分割按日期执行，purge/embargo 至少覆盖结果重叠期，避免相邻样本交叉泄漏；探索、确认、未来保留集身份永久登记。

校准事件可定义为“指定 horizon 净超额回报超过预登记阈值”，不能只写“看涨”。概率区间原样锁定；若计算 Brier score/可靠性图，需要锁定代表值（如区间中点）与分箱方法并记录其局限，或只报告区间覆盖和经验频率。小样本不给确定校准结论。未成熟/数据缺失标签不参加评分，报告删失；已泄漏样本单独展示，不计确认成绩。

复盘区分：判断与理由均正确；判断正确但理由错误；判断错误但过程合理；判断错误且存在可识别错误；随机/无法归因。机制是否兑现独立于价格结局检查。“后来涨了”不能证明原理由正确。

完成后更新永久记忆文件。若没有可准入的数据，只保存本轮阻塞与下一数据门槛；不要生成概率、结果或声称完成历史盲测。
