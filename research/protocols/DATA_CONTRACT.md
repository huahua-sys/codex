# Point-in-Time 数据契约

版本 1.0；2026-10-08 UTC。状态：协议已建立，尚无符合契约的实证数据。契约是数据准入纪律，不是市场预测规律。

## 一条记录必须回答的问题

| 字段 | 含义与要求 |
|---|---|
| `source_id`, `record_id`, `source_path`, `source_sha256` | 可追溯来源、唯一记录和内容哈希；源文件保持原样 |
| `asset_id`, `market`, `instrument_type` | 稳定历史标识；代码变更映射独立保存，不能只用当前 ticker |
| `observed_period_start/end` | 指标所测时期；不得冒充发布时间 |
| `published_at`, `publication_timezone` | 原始公开日期与时刻、时区，来自可核验公告/档案 |
| `available_at`, `availability_evidence` | 预设研究信息集真正可获得的最早时刻及证明；应不早于公开且无保密/渠道限制 |
| `ingested_at` | 本实验室导入时刻，只作审计，不能证明历史可得性 |
| `vintage_id`, `revision_of` | 当时发布版本、修订链；保存初值与修订值，按 T 取版本 |
| `units`, `currency`, `accounting_basis` | 单位、货币、会计准则、口径、季度/年度累计与单季口径 |
| `pit_status` | `VERIFIED`、`POINT-IN-TIME UNCERTAIN`、`POST_CUTOFF` 或 `INELIGIBLE` |
| `missing_reason`, `quality_flags` | 缺失原因、精度、重复、冲突、异常、授权/覆盖限制 |

时间以带时区的 ISO-8601 保存，同时保留原始文本和转换规则。仅知道公告日期但不知时刻时，不推定当天零点、开盘或收盘可得；可在证明该日期真实公开后，按预登记保守规则推迟到下一完整交易日，并报告敏感性，仍保留精度限制。无法证明原始公开日期则不能用保守延期消除未知性。文件 mtime、上传时间、页脚更新日期、当前网页抓取时间均不能填入 `available_at`。

`available_at <= cutoff_at` 是必要条件，还需核验版本、当时渠道、资产归属及口径。不知道当时能否获得的字段进入隔离区，不进入主要确认检验。若仅有今日修订后的宏观/财务数值，记录 `POINT-IN-TIME DATA REQUIRED`。同一时间存在多个相冲突来源时保存全部来源，事先指定来源优先顺序，不能按照结果挑选。

## 最低可运行数据包

1. **历史样本框**：至少一个市场的历史可交易资产表、纳入/移出时间、IPO、退市、代码变化和流动性资料；或明确单一当时可投资标的的局部案例，并承认无法做总体/横截面推断。抽样框不能由当前仍上市公司倒推。
2. **T 之前的信息**：每项拟研究信号对应的真实源资料、发布时间、当时版本；无资料则减少问题而不补值。财报、新闻与宏观不是每项实验都必需，但被假设依赖的字段必须齐备。
3. **T 前后价格与公司行动**：当时信号用的未被未来复权污染的价格、成交/执行价格、分红、拆合股、配股、并购、退市终值；相同市场日历、停牌与可交易限制。
4. **对照与机会成本**：同币种、同交易/持有期的预登记总回报基准及现金/短债代理；不能事后挑最弱基准。
5. **成本与 FX**：可核验的费率/税费/价差/滑点/基金费用；不能重复扣净值中已含费用；跨币种汇率及取样时点。成本缺失只可报告明确假设下的敏感性，不得称已证实可执行净收益。
6. **原始来源清单**：文件校验值、字段说明、覆盖日期、版本、去重键、缺失/退市覆盖与可用性证据。

一周 horizon 最低需要可执行入场和离场价格、相关分红与行动、基准、日历及成本；还要长 horizon 才能评价 1–24 个月。样本尚未成熟时标签保持 `null` 与 `PENDING_HORIZON`；原始数据缺失时为 `UNRESOLVED_DATA`，两者均不算零收益或失败。

## 分类型要求

| 资料 | 关键陷阱 | 准入与处理 |
|---|---|---|
| 财报/经营指标 | 财期末与公告日混淆；重述；累计口径；跨币种 | 原公告和时刻；版本链；公布后才可用；同行比较先统一口径 |
| 历史分析师预期 | 只保存今日预测；回填；样本覆盖变化 | 预测快照和更新时间、当时覆盖家数，禁止事后共识 |
| 宏观/政策 | 修订；执行晚于宣布；发布时间时区 | 首次发布 vintage；宣布/执行分开；将政策权重视作待验证机制 |
| 新闻/内幕人/回购 | 修改新闻；交易日不等于公开日；计划不等于实施 | 原始首次公开时间与版本；分类公告/执行；回购实际成交、内幕人申报公开时间 |
| 价格/公司行动 | 前复权利用未来行动；停牌无成交；忽略分红退市 | 截止前特征使用当时已知调整；评估器独立计算真实前向总回报和可实现终值 |
| 指数/ETF | 当前成分倒灌；价格/NAV差异；幸存者偏差 | 历史成分与生效时间；可交易价格评估；管理费和现金分派；关闭基金保留 |
| 主动基金 | 存续选择；类别/经理变更；净值发布时间与申赎价格 | 历史类别、关闭/合并、披露与申赎截止；净值费用口径；不能按未知净值成交 |
| 债券/利率资产 | 用收益率变化代替总回报；信用/久期/流动性不同 | 利息、价格、久期、违约/清偿、交易报价；现金代理与现券/基金分开 |
| 黄金/商品代理 | 现货不可投资；期货展期；货币误配 | 明确可投资工具、展期/存储/基金成本和计价币种 |
| 资金流/仓位/期权 | 报告滞后；事后推断流量；覆盖变动 | 披露日和频率、原始快照；没有源资料就标缺失 |

## 数据质量验收

入库先统计记录数、覆盖期、资产数、字段缺失、发布时间精度、重复键、修订、幸存者/退市覆盖。按 `source_id + record_id + vintage_id` 检查唯一性；连接时确认资产、日期与版本粒度，禁止多对多复制。展示每一步筛选后剩余样本和排除原因。

检查时间逆序、时区、非交易日、股票拆合/币种变化、收益极值与跨来源冲突。样本差异和缺失是否与结局相关须由标签评估阶段报告，不以插值抹掉。所有指标保存计算公式及所用源记录 ID，复盘可以重算。

来源哈希和导入审计证明输入版本；不证明数据当时已公开，也不证明模型没记住未来。全部时间证据通过后才能把数据标为可用于局部遮蔽回放；不能据此宣布真实盲测。当前本轮数据包缺失，验收结果为 `BLOCKED_DATA_REQUIRED`。
