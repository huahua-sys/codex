# ROUND_001：首轮历史遮蔽复盘设计

计划日期：2026-10-08 UTC。状态 `BLOCKED_DATA_REQUIRED`。此文件是尚未运行的计划，不能作为真实历史案例、预登记锁定或预测。

## 本轮实际能做什么

项目只有任务说明，没有价格、总回报/公司行动、财报、历史新闻、macro vintage、历史成分股、基金或可核验发布时间数据。本轮只能完成数据审计、研究协议、模板、初步研究方向与路线图。真实历史 T、资产、概率、前向标签与校准均无法生成。

“先完成一轮盲历史复盘”在该资料状态下不满足准入门槛；本轮完成的是可执行性检查，记录在 `research/replays/ROUND_001_BLOCKED.md`，不是完成一次实证。不从模型记忆补一段著名历史故事。后续经用户提供可准入资料才可实例化以下流程。

## 第一批抽样程序（未执行）

1. 在看任何结果前验收资料，保存输入清单和 PIT 证据。使用真实历史可交易 universe，保留退市、关闭与代码变化。价格质量不足、时间戳不确定与无法交易逐项记录，不能只保留当前存续赢家。
2. 在可证明信息覆盖的市场选择当时可交易资产；市场与时间跨度由资料覆盖及问题可证伪性确定，不以事后收益挑选。确定日历、交易时段、截止时区与周度固定截止点，例如“当地最后交易日收盘后”须由源信息可得性支持。具体市场、日期、资产、seed 和阈值尚未填写，不能称已预登记。
3. 依据当时公开字段构造候选信号层。首轮只选 1–2 个资料最可靠、机制最明确的假设；选择准则是可得性、可证伪性、研究价值和成本，不能看结果后挑表现最佳者。记录已知模型记忆和探索暴露。
4. 计划预算最多 24 个 episode，仅为人工审阅/低计算试点上限，不是统计充分样本数。用固定 seed 从 universe × 周截止点取样，信号出现和未出现各保留普通资产；按当时行业/规模/流动性/regime匹配，存抽样概率。若某层没有可准入样本，报告空层，不事后找赢家填充。
5. 控制重叠：避免把同资产相邻周或同行业同事件当独立证据；事先登记日期/资产簇和 purge/embargo，主要 horizon 仅一个，其余期限为次要描述。以最简单分布/匹配比较为主，不做大策略搜索。
6. 管理员按 `available_at <= T` 制作 ex-ante 资料包；研究者写理由、宽概率、卖出/否证/等待条件；锁定所有文件与 manifest 哈希。只有锁定完成后独立评估者读取标签。
7. 标签评估全部样本，不仅信号样本。正向、反向与中性阈值先登记；成熟结果产生如下分类。没有成熟数据保持 `PENDING_HORIZON`，缺数据为 `UNRESOLVED_DATA`。

| 目标覆盖 | 如何从原样本产生 | 当前实际案例数 |
|---|---|---:|
| 成功 / Positive Cases | 信号出现且达到预登记目标事件 / 决策效用；买入可为上涨，SELL/WAIT 可为避免损失或改善净结果 | 0 |
| 失败 / Negative Controls | 信号出现但未达到该假设目标标准 | 0 |
| False Negatives / Missed Winners / Missed Risks | 买入无信号但达到上涨目标为漏掉赢家；SELL/WAIT 无风险信号但发生损失为遗漏风险，分别按假设定义 | 0 |
| 无结果 / Ordinary Cases | 事后位于预登记中性带，或无经济意义超额回报 | 0 |
| 反向 / Opposite Cases | 同类条件下达到反向标准；可附加负对照标签 | 0 |
| 无信号普通案例 | 无信号层完整保留，包含上涨、下跌与中性结果，不依目标类别删除 | 0 |

上述类别是评估覆盖目标，不是按已知结局选样或强制配额。“正向 / 反向”针对预登记假设方向或决策效用，不统一等同于股票涨跌。主标签定义互斥，多标签附加信息避免重复计数。若结果中缺少某类，记录缺口；下轮按事先规则扩大普通 universe/日历，不回看结果选取补充“成功/失败”案例。事后专门挑选的案例只归探索库。

## 评估与停止

每个 episode 保留宏观、行业、公司、估值、政策、新闻、资金、内幕人/机构、趋势、情绪和仓位等当时证据；缺的字段标缺失。price-in、Capital Cycle 与每股现金传导均列问题而非默认答案。最早模拟成交必须在 T 后的下一可交易时点，主动再决策间隔至少一周。

1 周、1/3/6/12/24 个月观察窗口须明确对齐与成熟规则，包含总回报、成本、基准、现金机会成本、FX、退市与可交易性。等待也是正式动作。原理由与后续机制分开评分，命中不等于逻辑正确；小样本只能找到可反证的问题。

历史遮蔽不能保证 LLM 不知道结局，结果标 `MASKED_HISTORICAL_REPLAY`，记忆污染样本从确认集合隔离。可靠前瞻验证必须在未来结果形成前完成 `PROSPECTIVE_PREREGISTERED` 锁定。

本轮不运行、不揭晓、不生成复盘发现的候选规律。现阶段研究方向须标明来自用户 prompt/经济机制先验；不声称来自本轮实证。更新长期记忆后停止。
