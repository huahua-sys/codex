## 执行

在项目目录运行：

```bash
python3 scripts/phase3_forward.py register
python3 scripts/phase3_forward.py status
python3 scripts/phase3_forward.py capture --month 2026-10
python3 scripts/phase3_forward.py evaluate --month 2026-10
```

`register`已执行并锁定；重复调用仅验证。`status`从追加决策锁推导当前状态，原计划中PENDING字段永不回写。**没有安装cron，也没有部署无人值守调度。** 后续任务必须在真实时点实际运行capture；提供脚本和待执行计划不等于已执行LIVE FORWARD TEST。

`capture`仅在月末工作日美国16:00正常收盘以后，或之后3个日历日内允许运行；夏令时20:00UTC、冬令时21:00UTC。当前10月9日调用会拒绝，拒绝发生在联网和写决策目录之前。没有 `--now`、`--as-of` 或历史导入通道。来源必须由实际运行当时的HTTP下载产生，保存原字节、请求/接收/留存时间、响应Date/ETag等头和SHA；没有当时快照就保持漏失，不能后来导入历史资料再冒充LIVE。一个月份已有尝试目录时拒绝覆盖；失败及部分资料保留，重试须新版本并明确其真实时点。

实际cutoff为本次所有来源留存以后锁定判断的真实UTC时间。若周末或宽限内延迟捕获，明确 `ACTUAL_DELAYED_CAPTURE_NOT_BACKDATED`，不能称10月30日事前判断。月份特征只取所登记月份及之前已完成的价格，来源中更晚已完成的会话不进入月末特征。假设入场必须严格在**实际cutoff**以后首次来源观察开盘，不能回到月末价格成交。未完整会话被排除。原始来源中出现未核验拆分时相应变量/收益隔离，不偷用未来复权。

## 收益边界与验证

ETF采用provider-reported除息日经济再投资、固定50bp roundtrip成本假设；分红金额未逐笔独立核对，付款日执行尚未证明。美国SPY、GLD仅在与BIL同入/出会话时报告净基准差。BIL是短债ETF基准，不是无风险零波动现金。海外宽基是当地价格指数、不可直接交易；缺本地现金、FX及可交易代理时超额和组合回报保持UNKNOWN。正常会话钟不证明特殊开盘、停牌或完整交易日历。这里没有主动组合、期望收益或概率可供校准，标签只回答未来发生了什么。

工程检查记录见 `ENGINEERING_SAFETY.v001.json`。synthetic数据只验证提前/过期时间拒绝、冬季收盘时差、未完整会话排除及append-only哈希保护；不会成为任何投资规律证据。真实10月9日capture拒绝另有记录。SHA和本机UTC不是外部可信时间见证，也不是不可篡改存储；需要外部见证才能进一步加强真正前瞻证据。
